# App icon

`icon-1024-square.png` is the source artwork: Astro on the beach with the board and a
shaka, supplied as a finished picture. Every other file here is cut from it:

- `icon-1024.png`, `icon-512.png`, `icon-192.png`, `icon-180.png`, `icon-32.png` — rounded,
  for the web, the home screen and previews.
- `icon-512-square.png` — unrounded, for stores that apply their own mask.
- `favicon.ico` — 16 to 64.

`render.py` and `compose.py` are the earlier generated icon's pipeline (a Blender portrait of
the pug over a painted sunset) and are kept only for reference; nothing is built from them now.
